# Audio Library Organizer

Herramienta de línea de comandos para organizar automáticamente bibliotecas de audio por duración, extrayendo metadata real de cada archivo.

## Instalación

```bash
pip install -r requirements.txt
```

## Uso

```bash
python organizador.py --carpeta ./mi_biblioteca --umbral 30
```

## Por qué lo construí

Como productor musical, necesitaba una forma rápida de ordenar mis sesiones y loops sin hacerlo manualmente.
